## Why

Shoppers comparing similarly-packaged goods (e.g., 0.9 kg vs 1.5 kg) cannot easily tell which option is actually cheaper per unit. There is no project code yet, so we need to bootstrap a minimal cross-platform mobile app that does this single calculation well — nothing more.

## What Changes

- Bootstrap a Flutter (Dart) project that builds for Android and iOS with no third-party dependencies beyond the Flutter SDK.
- Provide a single screen with two input fields (Price in rubles, Quantity as decimal) and an "Add" button.
- Append each added product to an unsorted list, auto-naming entries "Product 1", "Product 2", …
- For each list item, compute and display unit price as `Price / Quantity`, rounded to two decimal places.
- Visually highlight the product with the lowest unit price (e.g., light-green background and/or a "best" indicator), independent of list position.
- Allow deleting any product directly from its row via a trash icon.
- Use Material Design 3 with `ThemeMode.system` so light/dark follows the OS setting.
- Keep code minimal — prefer a single `main.dart`, splitting only if it improves clarity.

## Capabilities

### New Capabilities
- `unit-price-compare`: Entering products as (Price, Quantity) pairs, computing unit price, listing them in insertion order with auto-generated names, highlighting the lowest unit price, and deleting entries.
- `app-shell`: Flutter project scaffold targeting Android + iOS, Material 3 theming with system light/dark mode, and the single-screen layout (inputs + Add button + list).

## Impact

- **New code**: `pubspec.yaml`, `lib/main.dart`, and the platform folders generated by `flutter create` for Android and iOS.
- **Dependencies**: Flutter SDK only. No packages added to `pubspec.yaml` beyond Flutter defaults.
- **Build targets**: Android and iOS must build cleanly (`flutter build apk`, `flutter build ios --no-codesign`).
- **Out of scope**: persistence between sessions, sorting controls, currency selection, product editing, sharing/export, web/desktop targets, automated tests beyond the default smoke test.
